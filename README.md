# Sistema de Cadastro de Produtos — Empresa de Água

Projeto acadêmico desenvolvido para a disciplina de **Linguagem de Marcação e Formatação**, com foco na criação de uma interface web para uma empresa do segmento de distribuição de água.

## Sobre o projeto

A aplicação simula um sistema interno utilizado por funcionários de uma empresa de água.

O usuário inicia o acesso por uma **tela de login** e, após a entrada no sistema, é direcionado para uma página de **cadastro de produtos**, utilizada neste projeto para o cadastro de botijões de água.

O principal objetivo do projeto é realizar a **validação dos campos do formulário**, garantindo que os dados inseridos correspondam ao tipo esperado.

## Funcionalidades

- 🔐 Tela de login para acesso do funcionário
- 📦 Cadastro de produtos
- 🔢 Validação de campos numéricos
- 🔤 Validação de campos de texto
- ⚠️ Exibição de mensagens de alerta para dados inválidos
- 🛡️ Tratamento de exceções utilizando JavaScript

## Validação dos campos

O sistema verifica o tipo de dado informado pelo usuário.

Por exemplo:

- Campos numéricos aceitam apenas números;
- Campos de texto aceitam apenas letras;
- Quando um valor inválido é inserido, o sistema exibe um **pop-up de alerta** informando o usuário sobre o erro.

Essa validação contribui para evitar entradas incorretas e melhorar a experiência durante o preenchimento do formulário.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Contexto acadêmico

Projeto desenvolvido para fins acadêmicos na disciplina de **Linguagem de Marcação e Formatação**, com o objetivo de praticar conceitos de desenvolvimento web, formulários, validação de dados e tratamento de exceções em JavaScript.
