Esse projeto foi desenvolvido para validar campos de um formulário, garantindo que o usuário digite apenas o tipo permitido em cada campo.   Ele exibe mensagens de alerta caso o usuário tente inserir valores incorretos, melhorando a experiência e a segurança dos dados.

Funcionalidades

- ✔️ Permite *apenas números* em campos numéricos (ex: código do produto)  
- ✔️ Permite *apenas letras* em campos de texto (ex: descrição do produto)  
- ✔️ Exibe *alertas* quando o usuário digita algo inválido  


Projeto realizado apenas para fins de estudo.
